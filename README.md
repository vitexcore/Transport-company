# Jadoo Travel Landing Page

This is a travel landing page I built while practicing HTML and Tailwind CSS v4. Nothing fancy — just me trying to get better at frontend development one project at a time.

---

## What is this?

It's a landing page for a fictional travel company called **Jadoo**. It has a hero section, some destination cards, a testimonials section, and a footer with app download buttons. I tried to make it look close to the original design.

---

## What I used

- HTML
- Tailwind CSS v4
- Font Awesome for icons
- Iconify for the Google Play icon
- Google Fonts (Volkhov and Poppins)

---

## How to run it

First, make sure you have Node.js installed. Then:

```bash
# Install dependencies
npm install

# Start Tailwind watcher
npx @tailwindcss/cli -i ./src/input.css -o ./public/output.css --watch
```

Then just open `index.html` in your browser and you're good to go.
